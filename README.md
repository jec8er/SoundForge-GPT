# SoundForge — part of SaborClick Studio

The independent version is ready on [SAlesC/github-runtime](https://github.com/jec8er/SAlesC/tree/github-runtime), with integration into main proposed in [PR #2](https://github.com/jec8er/SAlesC/pull/2).

The module lives in `src/studio.tsx` and `lib/domain.ts`: editable English/Spanish product launch scripts, browser microphone recording, and script/audio downloads. Templates use supplied facts; AI voice generation and automatic publishing are not connected.

The standalone branch runs using React/Vite, Express and SQLite, independent of Sites. Follow that branch's README for owner access and startup. Main still contains the earlier implementation until PR #2 is integrated.

This repository was originally empty. Maintain SoundForge in the canonical project to avoid divergent copies.
